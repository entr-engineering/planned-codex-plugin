# Planned Codex plugin

Bring [Planned](https://planned.com/) into your Codex workflow.

## What it does

Access your events and use the Planned tools available to your account without leaving Codex.

## Example prompts

- “Show me my upcoming events.”
- “Find the contracts for this event.”
- “What still needs my attention?”

## Requirements

- A Planned account with access to the relevant events.
- Authentication with Planned when the plugin is installed.
